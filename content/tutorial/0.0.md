# 零、前言

TNT 非常喜欢打麻将，自从学会打麻将开始，他就一直在努力成为一代雀神。可惜有言道：

> 打牌，首先手气不能太差。

因此 TNT 一直也没怎么赢过，尤其是大牌，几乎没做过任何大牌。

不过，TNT 觉得麻将是一款将博弈论和概率论很好地结合在一起的游戏，非常有意思（肥肠有意思）。所以在了解了众多规则后，TNT 决定拉更多的人来入坑麻将。这样不但有人陪自己练麻将，还可以狠狠嘲讽新人（不是）。

在传播“麻将教”的过程中，TNT 发现周围人的麻将水平良莠不齐。因此，为了更方便、更简单地传播“麻将教”，TNT 决定编写这个教程。

另外，TNT 和他的好朋友们经常线下搓麻，但是不计分还玩什么大牌！所以 TNT 研究出了一套分数系统，可以适配几乎所有的麻将规则。虽然分数换算上还有一些不合理，但是起码制定了一个简单的标准，让麻将尽可能从“随便玩玩”进化到一种标准竞技。

***重要声明：在玩麻将这款游戏时，切忌赌博！！！***
